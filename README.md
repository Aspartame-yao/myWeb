# MGLAB — Make Ideas Real

MGLAB is Mengyao Wang's interactive product portfolio. The site combines a transparent WebGL cat-head hero with the scroll-driven 3D grid system from Codrops' MIT-licensed [Staggered3DGridAnimations](https://github.com/codrops/Staggered3DGridAnimations).

## Features

- React Three Fiber glass/ice cat model with procedural normals and environment reflections
- GSAP ScrollTrigger and Lenis-powered 3D project grid
- Repeating project cards with hover labels
- Accessible two-column project detail overlay
- Responsive desktop and mobile layouts

## Local development

Requires Node.js `>=22.13.0` and pnpm.

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```

## Content

Project images and Demo URLs are placeholders until final portfolio material is supplied. The current interface deliberately avoids invented metrics or confidential information.
